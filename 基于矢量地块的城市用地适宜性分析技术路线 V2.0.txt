🎯 核心思想
以规划地块为分析单元，全程矢量处理，保留完整属性信息
•	✅ 避免栅格-矢量转换导致的字段丢失
•	✅ 保持规划地块的完整性和语义
•	✅ 简化后续属性查询和展示
•	✅ 符合城市规划业务逻辑
---

📊 数据准备
输入数据
1.	分析区域（必选）
•	类型: Shapefile/GDB Feature Class
•	内容: 城市规划用地地块
•	字段要求: 包含用地类型、用地名称、地块编号等规划属性
•	示例字段: PLOT_ID, LAND_USE, PLOT_NAME, AREA, ZONE_CODE
2.	限制因素（可选，多个）
•	类型: Shapefile/GDB Feature Class
•	内容: 生态保护区、水源保护区、文物保护范围等
•	作用: 通过矢量差集剔除不可建设区域
3.	POI因子（必选，多个）
•	类型:
•	矢量: Shapefile/GDB Feature Class（点、线、面）
•	栅格: TIF/IMG（距离栅格、坡度栅格等）
•	示例: 地铁站、学校、医院、公园、道路等
输出数据
•	结果图层: Shapefile/GDB Feature Class
•	字段结构:
		原始字段（保留）:
		  - PLOT_ID: 地块编号
		  - LAND_USE: 用地类型
		  - PLOT_NAME: 地块名称
		  - AREA: 面积
		  - ...（其他规划属性）

		新增字段（分析结果）:
		  - Score_Metro: 地铁可达性得分 (0-10)
		  - Score_School: 学校便利性得分 (0-10)
		  - Score_Hospital: 医疗便利性得分 (0-10)
		  - ...（其他因子得分）
		  - FINAL_SCORE: 综合适宜性得分 (0-10)

🔧 技术路线详解
阶段 1: 地块筛选（限制因素处理）
目标
剔除限制建设区域，保留可建设地块
技术方案
•	工具: ArcGIS Pro GP 工具 - Erase (擦除) 或 Pairwise Erase
•	操作流程:
		输入要素: 分析区域地块 (analysis_area.shp)
		擦除要素: 限制因素1 (constraint1.shp)
		输出要素: temp_suitable_area_1.shp

		→ 继续擦除限制因素2、3...

		最终输出: suitable_area.shp
关键点
•	✅ 保留所有原始字段: Erase 工具会保留输入要素的所有属性
•	✅ 地块完整性: 不会破坏地块边界（除非与限制区域重叠）
•	⚠️ 可选的面积过滤: 在擦除后，使用 SQL 查询删除面积过小/过大的地块

阶段 2: 单因子评分（核心改进）
目标
为每个地块计算各POI因子的得分，作为新字段追加到地块图层
2.1 矢量POI处理（如地铁站、学校）
步骤 1: 计算距离栅格
		工具: Euclidean Distance (欧氏距离)
		输入: 地铁站点图层 (metro_stations.shp)
		输出: 距离栅格 (dist_metro.tif)
步骤 2: 栅格分区统计
		工具: Zonal Statistics as Table (分区统计为表)
		输入区域数据: suitable_area.shp (地块图层)
		区域字段: PLOT_ID (地块唯一ID)
		输入值栅格: dist_metro.tif (距离栅格)
		输出表: zonal_stats_metro.dbf
		统计类型: MEAN (平均值) 或 MIN (最小值)
步骤 3: 距离转评分
		使用自定义分类或线性变换:
		- 方案A: 用户自定义间隔
		  0-500m   → 10分
		  500-1000m → 8分
		  1000-2000m → 5分
		  > 2000m   → 0分

		- 方案B: 线性反比
		  Score = 10 * (1 - distance / max_distance)
步骤 4: 字段追加
		工具: Join Field (字段连接)
		输入表: suitable_area.shp
		连接表: zonal_stats_metro.dbf
		连接字段: PLOT_ID
		添加字段: MEAN → 重命名为 Score_Metro

2.2 栅格POI处理（如坡度、噪声）
如果POI本身已经是栅格（如坡度栅格、噪声栅格），跳过距离计算，直接分区统计：
		工具: Zonal Statistics as Table
		输入区域数据: suitable_area.shp
		输入值栅格: slope.tif (坡度栅格)
		输出表: zonal_stats_slope.dbf
		统计类型: MEAN

		→ 然后将统计结果转换为评分（0-10）
		→ 追加到地块图层: Score_Slope

阶段 3: 加权叠加（字段计算）
目标
根据各因子权重计算综合得分
技术方案
使用 Calculate Field (字段计算器) 或 SQL 表达式
阶段 4: 结果输出与可视化
